# n8n Workflow Collection

This repository contains a set of simple n8n workflows designed for testing and experimenting with integrations across various services and APIs.
The goal is to provide a lightweight sandbox for exploring automation logic, trigger behavior, and data flow between connected tools.

## Features

1. Basic workflows demonstrating interaction with common n8n nodes (HTTP, Webhook, Email, etc.)
2. Example integrations with third-party APIs and services
3. Ready-to-import .json workflow files for quick testing
4. Useful for learning, prototyping, and debugging custom automations

## Usage

- Clone the repository.
- Import any .json file into your local or cloud n8n instance.
- Adjust credentials and endpoints as needed.
- Run and observe workflow behavior or extend for further testing.

## Notes

These workflows are for experimentation and educational purposes only.
They are intentionally minimal and may require configuration before production use.
